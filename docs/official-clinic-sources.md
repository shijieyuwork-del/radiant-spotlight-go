# Official hospital photos and credentials

Public source review: 28–29 October 2026.

This update adds 16 institution-specific official website photographs and 27 sourced credential records. With existing photographs, 81 of 102 static directory cards have source images. The remaining 21 retain the no-photo state; no stock or mismatched branch images were substituted. Admin-managed photographs and deliberately empty galleries retain precedence.

Grades are attributed to the linked public source. No current licence verification or procedure-specific authorization is inferred. Historical JCI claims and industry 5A ratings are not presented as current hospital-grade or licensing certificates. The directory distinguishes the Lecheng medical tourism zone from a single hospital.

The Jiajianmei Chinese name/location is corrected to the outpatient clinic in Xicheng; its established English URL identity is retained. Shulan (Hangzhou) is marked privately operated.
