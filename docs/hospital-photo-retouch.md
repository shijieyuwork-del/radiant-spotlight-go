# 医院照片精修 — 2026-09-08

用户要求改善医院照片中的电线/电线杆、近景路人和暗沉光线。先对现有 63 张实拍做缩略图审查，再选取以下 14 张逐图精修。其余照片保留现有轻度显示调色。医院目录与医院详情共用同一照片映射。

## 处理方式

- 使用内置 imagegen 编辑已核实的原始医院照片，保留建筑主体、拍摄角度和医院识别信息。没有用无关建筑替代医院。
- 原始 WebP 不覆盖、不删除。每张最终图保存为 `src/assets/real-photos/retouched/<名称>-retouched-v1.webp`。
- 精修版本已完成曝光与色彩调整，组件不再对它们叠加额外的 CSS 提亮，以避免白墙过曝。
- 各来源 JSON 保留作者、许可、历史拍摄时间、院区说明和原始来源链接；`modifications` 说明修图，`originalImgPath` 指向保留的本地原图。
- 原来没有实拍的医院继续保留无图状态。
