## 执行原则

1. **内容真实性**：不编造医生、案例、价格。专家与视频区只展示数据库里已有的记录；价格用 treatments.ts 已发布区间 × 城市系数，标注"市场参考"。
2. **合规**：页面文案用 expert（禁止 doctor 面向用户表述），挂载 MedicalDisclaimer，不提供医疗建议。
3. **互链**：每个落地页链回 procedure guide 与城市页，并互链同城市/同手术的其他落地页；新 URL 进 sitemap.xml。
4. **测量**：发布后在 Search Console 观察 Tier 1 关键词展示/点击；排名进前 20 后启动 Tier 2。
