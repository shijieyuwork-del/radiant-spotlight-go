# 医院实拍图片替换记录

本次范围为 `/clinics` 医院目录。保留原有医院资料、搜索和城市筛选，不修改医生照片、首页服务场景图、DNS 或域名绑定。

## 图片来源与显示规则

- 每张图片必须匹配具体医院；不同院区、历史建筑和旧照片在来源说明中明确。
- 不使用 AI 生成图、无关医院图片或通用室内图填补缺口。
- 没有核实实拍的机构保留资料，显示“暂无实拍图片”；图片加载失败也显示同一占位。
- 使用 Wikimedia Commons 单张文件页面所标注的可商用许可，并保留摄影者、来源链接、许可链接、拍摄时间和转换说明。
- 竖幅照片保留完整构图，横幅照片响应式裁切；未重绘建筑、添加招牌或修造医院形象。
- 每个城市的普通目录卡片优先显示有实拍者，关联已发布专家的诊所仍保持置顶。
- 旧示意图文件仍留在版本历史/项目中，目录不再引用它们，方便恢复。

## 更新与核验

在项目根目录执行：

```sh
node scripts/audit-hospital-photos.mjs
npx vitest run src/test/hospital-photo.test.tsx
npx tsc --noEmit -p tsconfig.app.json
npm run build
```

审计脚本列出当前覆盖数量、缺图名单，并检查资产、来源字段和名称冲突。构建流程先运行该审计；缺少清单内图片时构建失败，不得发布。本地准备图片时，未完成的记录显示无图占位，不使整站崩溃。

本地浏览器已检查 320、375、768、1024、1440 像素宽度，未出现页面横向溢出；已验证城市筛选、名称搜索、无结果状态、清除筛选、中英文切换，以及键盘展开图片来源。5 项新增组件测试覆盖无图、实拍加载、署名链接、加载失败回退和竖图构图。

最终 TypeScript 检查、修改文件 ESLint 检查、5 项新增测试及 `npm run build` 均通过。生产包浏览器检查显示 102 条记录、64 张实拍、64 处来源署名、38 个无图占位；逐张图片解码成功，无生成图引用。

继续补图时，先核实医院/院区和照片使用许可，再把 WebP 与来源记录一起提交。不能仅凭“网上能看到”推定医院授权。用户已表示拥有的百科图片，可在收到可访问的原图及对应医院信息后继续处理。
