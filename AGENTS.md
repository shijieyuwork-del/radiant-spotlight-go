# AGENTS.md

## Rules

- Published case and expert SEO shares metadata helpers and public-record snapshots with the existing static renderer; build-time reads fail closed so incomplete database fetches cannot silently drop indexed routes.
- Static case payloads contain only public records scoped to each route; runtime lookups and media redirects recheck publication, and eight-character ID collisions fail closed rather than resolving to an arbitrary case.
- Sitemap lastmod uses authoritative row timestamps only, never the build date, because rebuilding is not a significant page content update.

- Medora imports validate the fixed source allowlist and admin identity server-side; public video queries default to bounded pages so partner media cannot create unbounded downloads or signing work.

- User-facing contact details (WhatsApp number, email) come from `src/lib/consultation-handoff.ts`; never inline a second `wa.me/<number>` or `mailto:` literal, because the coordinator contact changes in one place.
- Floating contact controls share one bottom-right rail: the WhatsApp bubble is pinned (visible on mobile without a scroll gate) and the consultation shortcut stacks above it via `.float-rail-above-wa` in `src/index.css`; new floating UI must not reuse that corner or unpin the bubble on mobile.
- Every floating control is skipped on `/admin/*` screens and steps aside while the analytics consent prompt is open, so internal tooling and the privacy prompt keep the bottom edge to themselves.
- Public browser data access uses the app-owned dynamic client loader; generated integration files remain untouched so SDK changes cannot break fluent queries or managed authentication.
- Viewport-deferred homepage sections render their original components on the server, keeping complete static body text without changing the prerender pipeline.
- Local responsive photos are generated by Vite image transforms with original imports as fallbacks; authorized remote media and source attribution are preserved.

- Treatment-city routes share the published snapshot and exact procedure/city matching; emit only combinations with three covered published cases or two published experts, so builds and runtime do not create thin pages.
- Localized sitemap alternates reference only existing independently prerendered language routes; client-side language selections never create alternate URLs.
